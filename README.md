# 🚀 Riddhika Ghosh — Portfolio

A premium, modern portfolio website built with **HTML, CSS & JavaScript**.

## ✨ Live Preview

🔗 **[Visit Portfolio](https://riddhikaghosh.github.io/Riddhika-Portfolio/)**

## 📋 Sections

- **Hero** — Introduction with animated profile, floating badges & social links
- **About** — Bio & animated stat counters
- **Skills** — 6 skill cards with progress bars (UI/UX, Web Dev, Visual Design, etc.)
- **Projects** — NectarSky, PolyBot, LifeLink
- **Experience** — Timeline of internships
- **Education** — Academic journey cards
- **Contact** — Email, phone, location & social media links

## 🎨 Design Features

- Dark premium theme with red/coral gradient accents
- Scroll-triggered animations & micro-interactions
- Cursor glow effect
- Glassmorphism cards
- Fully responsive (mobile, tablet, desktop)
- Google Fonts (Inter + Space Grotesk)

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
